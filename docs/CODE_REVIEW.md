# 代码评审清单

供本仓库变更评审使用。按改动范围勾选；不适用项写明原因。

## 正确性与边界

- [ ] 程序生成的观测事实、时间、规则和证据没有交给模型伪造。
- [ ] Preset 固定合同、Managed Custom Evidence、Manual Raw 请求互不越权。
- [ ] Profile Identity / 请求快照在请求期间稳定；取消、错误和重试语义明确。
- [ ] 修改没有触碰只读生产项目、真实凭据或忽略的本地输出。

## 安全

- [ ] Key 只从既定凭据边界解析；不进入 Profile、Trace、Evidence、响应、日志或测试输出。
- [ ] URL、请求大小、错误码和取消仍受控；没有添加任意 Header 或隐藏联网行为。
- [ ] 自动测试只使用临时存储和虚构值，没有真实网络请求。

## 验证与交付

- [ ] 新行为有针对性 Python / Browser 回归测试。
- [ ] 运行与风险相符的完整回归、JS 检查和 git diff --check。
- [ ] 文档链接、目录地图与当前代码一致。
- [ ] 检查 Git diff/status，未提交密钥、模型或用户本地数据。
