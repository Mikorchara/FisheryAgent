# Roadmap

## V0.1 — completed baseline

- Domain contracts and deterministic Mock data.
- Deterministic water-quality diagnosis.
- TF-IDF knowledge retrieval baseline.
- Provider-neutral Model Gateway, Cloud/Local profiles, and OpenAI SDK adapter.
- Offline tests and Mock Demo.

## V0.1.1 — next validation

- Validate a real local model on the GPU workstation.
- Check streaming behavior and compatibility with the selected OpenAI-compatible service.
- Record observed model identity, latency, error handling, and service-specific differences.

## V0.2 — future

- Design read-only Tool Calling, tool schemas, and a tool permission model.
- Keep deterministic diagnosis under application control.

## Later research

- Agent behavior, memory, and Digital Human integration are research topics; none is implemented in V0.1.
