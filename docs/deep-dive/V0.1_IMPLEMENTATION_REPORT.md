## RISKS / OPEN QUESTIONS

1. **检索等价性：** 当前运行环境无 scikit-learn，默认纯 Python TF-IDF 重现其核心设定，但边缘分词、特征排序和分数可能与 scikit-learn 不完全一致。关键词回退的召回能力也较弱。V0.1 尚无人工标注检索评测集。
2. **知识来源：** 原始 JSON 有整体版本，但缺逐块文献出处/标题。V0.1 使用 `legacy:eel_knowledge.json`，不编造来源。知识中包含具体养殖与用药文字，投入实际建议前应补来源和审查。
3. **规则语义：** 生产 `get_alarms()` 可对同一指标叠加多个阈值告警；V0.1 收敛为每指标最严重一条。这保留阈值边界，但不是逐条告警列表的完全复刻。
4. **输入政策：** `invalid`/`stale` 当前会产生质量警告，仍允许 Mock 模型生成带不确定性结果。真实接入前需决定何时直接停止生成并要求复测。
5. **真实 Adapter：** HTTP 连接、SSE、超时和重试只经过假 transport 离线测试；尚未对真实服务端验证。`total_timeout_s` 为请求级预算，stream idle 由读取超时控制。
6. **记录保留：** JSONL trace 默认追加到本地 `outputs/`，V0.1 仅在 README 说明手动保留/清理原则，未实现轮转或自动删除。
7. **V0.2 起点：** 在真实 Gateway 验证和检索评测之后，先做 `current_water_quality` 与 `search_knowledge` 两个受限只读 Tool，加入 schema、权限、步数上限和审计；Advice 的确定性诊断继续固定执行。
