# 水质历史图 UI 实验

实现范围为 `Fishery_AI_Prototype/apps`，尚未同步到独立 Fishery_Management。不改变监测事实、诊断阈值、工具、模型或预算。

## 数据与时间范围

- 页面读取 `/api/bootstrap` 内 `monitoring.trend`，由 `MonitoringService` 从当前实例的有界存储历史投影得到。
- 图表在前端筛选最近 5、10、30 分钟、1 小时或全部已返回历史，默认仍为 30 分钟。两张图共用同一个“历史范围”选择，刷新和页面切换保留选择。
- 范围以最后一条可解析观测时间为终点，不以当前电脑时间滑动旧数据；端点包含在范围内。它不会请求或补造更多历史。
- `/api/monitoring/history` 原接口使用 channel/limit，而不是上述档位枚举；本轮无需后端修改。不要把图表筛选与 AI 历史工具的独立时间合同混为一谈。
- 去重、真实时间间距、无效值排除和跨会话/缺失/断流断线沿用 `chartGeometry()`，不平均重复时间记录、不填补缺失。

## 单指标图

普通 marker 半径由 3 缩为 1.35 SVG 单位；超过 120 个点或相邻点间距小于 2.5 时缩为 0.65，并降低透明度。折线保持清晰，所有原始有效时间点仍保留，不进行抽样删点。

使用按时间寻找最近真实记录的游标，不用互相覆盖的大命中圆。悬停/点击可查看时间、原始值和单位，高亮点半径为 4；键盘聚焦图表后使用左右方向键、Home/End，Esc 关闭提示。窄屏保留图内横向滚动，不压缩时间刻度。

## 三指标综合图

**每项指标在当前所选时间范围内独立 Min–Max 归一化：**

```text
归一化值 = (原值 - 本指标最小值) / (本指标最大值 - 本指标最小值) × 100
若本指标没有变化：统一显示在 50
```

水温橙色实线、pH 紫色长虚线、溶解氧青绿色短虚线，共用 0–100 的无量纲 y 轴。颜色、线型与图例共同区分曲线；走势完全相同时允许重合，不人为错开制造差异。

采用这一方案的原因：诊断层虽然有水温/pH 范围，但溶氧只有正常下限，页面 DTO 也没有统一的业务参考范围合同。因此不把诊断常量复制到前端，不虚构三个指标的共同适宜范围。

限制必须对用户明确：

- **仅用于比较趋势，不是原始大小、实际变化幅度、跨指标相关性统计或水质适宜度比较。** 微小变化也可能铺满 0–100。
- 切换时间范围或轮询引入新极值时会重新计算坐标，不能把不同时间范围的归一化高度直接比较。
- tooltip 始终显示同一条真实记录的水温 °C、pH（无单位）、溶氧 mg/L，缺失/无效值显示“不可用”，不跨时间拼接或插值。
- 每项至少需要两个不同时间的有效窗口；不足时在图例说明，其他可用指标仍显示。所有指标不足时显示空状态。
- 未来若有统一、版本化的业务参考范围，可另行评估参考范围归一化；本轮不改后端合同。

## 实现位置与验证

| 位置 | 职责 |
|---|---|
| `apps/management_web/static/view-model.js` | 五档范围、指标展示元数据、原几何与归一化几何。 |
| `apps/management_web/static/components.js` | 两种 SVG 图表、小 marker、游标、原始值 tooltip 和键盘交互。 |
| `apps/management_web/static/app.js` | 保留单指标图，增加综合图，两图共用范围和已有轮询状态。 |
| `apps/management_web/static/styles.css` | 图例、tooltip、布局与图内滚动样式。 |
| `apps/management_web/tests/chart-ui.test.mjs` | 归一化、常量、质量/会话断线、原值 tooltip、marker 和时间边界。 |
| `apps/management_web/tests/monitoring-ui.test.mjs` | 实际页面五档选择、两图同步、默认值及轮询/导航保留。 |
| `apps/management_web/tests/chart_preview.py` | 仅内存虚构数据的本机人工预览，不打开数据库/凭据，不启用 AI 或 ingestion。 |

离线测试：在实验仓库根执行 `node --test apps/management_web/tests/*.test.mjs`。人工预览：使用本仓库 `.venv` 的 Python，以 `-I -B` 运行 `apps/management_web/tests/chart_preview.py`，访问 `http://127.0.0.1:8786/#monitoring`。预览十分钟后自动退出，或 Ctrl+C 停止，不应将该辅助程序当作正式启动入口。

### 本轮验证（2026-10-21）

- 93 项前端回归通过，包含 5/10 分钟边界、两图同步、常量、无效/缺失、重复时间、会话断点、tooltip 和键盘操作。
- 用 340 个纯内存虚构窗口进行浏览器检查：5 分钟 31 点、10 分钟 61 点、全部历史 340 点；三条线、原始值/单位提示正常。
- 桌面与 390px 窄屏窗口检查通过：图表内部横向滚动，页面未被撑宽；已补末端点像素取整边界，避免 hover/click 丢失端点。
- 未读取/写入业务数据库或凭据，未启用 Provider/NPU，未同步独立管理项目。

建议人工确认三色/虚实线、综合图放在单指标图下方，以及是否接受随所选范围重算的 Min–Max 视图。确认后可只同步本轮图表组件、展示逻辑、样式及对应回归；不要覆盖独立管理项目的品牌、启动器或其他独立改动。
