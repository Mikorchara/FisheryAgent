# 检测结果文本包 · 接收端对接规范

> 版本 1.0（2026-10-30）。发送端：Jetson 板上 fish_reporter 服务。
> 用途：板端把检测/异常汇总结果以 HTTP POST 推送到你们的服务；语言模型处理在你们端上做。
> 视频与文本不要求同步：视频预览走独立通道（见 §5），文本包按窗口产生、可配置为仅异常时发送。

---

## 1. 传输约定

- 方法：`POST`，URL 与端口由你们指定（示例：`http://<你们机器>:<端口>/api/fish/reports`）
- 请求头：
  - `Content-Type: application/json; charset=utf-8`
  - `X-Device-Token: <令牌>`（可选；若启用，令牌由你们发放，板端存于密钥文件，不落日志）
- 报文大小：通常 2~6 KiB，不超过 16 KiB
- 成功判定：响应 `2xx` 即视为送达，板端不再重发；响应体内容随意（如 `{"status":"accepted"}`）
- 失败处理：
  - `408 / 429 / 5xx / 网络错误`：板端指数退避重试，之后落盘缓存、定时补发（**`report_id` 不变**，你们需按 ID 幂等去重）
  - `400 / 401 / 403 / 413` 等语义拒绝：板端放弃该包并留档（重试无意义）
- 接收端只需实现一个幂等的 POST 处理器；不需要给板端开任何下行接口。

## 2. 发送时机

- 板端按 **60 秒窗口**聚合检测结果。
- 默认 `仅异常才发`：窗口内检出异常（`has_abnormality=true`）才推送；正常窗口只落盘不外发。
- 可切换为每窗口都发（`interval` 模式）。两种模式下，报文里的鱼群正常数据都完整保留，方便你们端上下文参考。

## 3. 报文格式（完整示例，字段值来自真实管道）

```json
{
  "schema_version": 1,
  "report_id": "20261030T124950-8f3a91c2",
  "device_id": "fish-monitor-orin-01",
  "sent_at": "2026-10-30T12:49:50+08:00",
  "window": {
    "start": "2026-10-30T12:49:11+08:00",
    "end": "2026-10-30T12:49:50+08:00",
    "duration_s": 38,
    "frames_processed": 3
  },
  "has_abnormality": true,
  "report_text": "【鳗鱼养殖智能巡检报告】\n设备：fish-monitor-orin-01\n时间：2026-10-30 12:49:11 ~ 2026-10-30 12:49:50（汇总 38 秒，处理 3 帧）\n\n一、鱼群概况\n检测到鳗鱼 2 条（跟踪去重），平均每帧 2.0 条，峰值 2 条，平均置信度 0.81。共处理 3 帧。\n\n二、健康异常\n处理 1 帧，发现以下异常（已按目标去重）：\n  - 身体溃烂 #1：连续出现 1 帧，平均置信度 0.71，位置 [x=150, y=95]\n合计 1 个异常目标。\n\n三、体长测量\n本窗口未进行体长测量。\n\n四、行为异常\n本窗口未进行行为异常分析。\n\n—— 本报告由鳗鱼监视器自动生成",
  "detection": {
    "unique_tracks": 2,
    "avg_per_frame": 2.0,
    "max_per_frame": 2,
    "avg_confidence": 0.81
  },
  "abnormalities": [
    {
      "label": "body_ulceration",
      "name": "身体溃烂",
      "targets": 1,
      "count": 1,
      "avg_confidence": 0.71,
      "last_bbox": [150.0, 95.0, 90.0, 50.0]
    }
  ],
  "behavior": null,
  "measurement": null
}
```

## 4. 字段说明

| 字段 | 含义 |
|---|---|
| `schema_version` | 本报文格式版本，当前恒为 1；你们可按版本分支处理 |
| `report_id` | 报文唯一 ID（窗口结束时间 + 随机后缀）；**重传不改 ID、不改内容**，用作幂等键 |
| `device_id` | 板端设备标识 |
| `sent_at` | 发送时刻，ISO 8601 带时区（+08:00） |
| `window.*` | 聚合窗口起止与处理的视频帧数 |
| `has_abnormality` | 窗口内是否检出异常；`仅异常才发` 模式下收到的包恒为 true |
| `report_text` | 完整中文报告（给人看/直接喂语言模型；换行为 `\n`） |
| `detection` | 鱼群统计：去重跟踪数、平均/峰值每帧条数、平均置信度 |
| `abnormalities` | 异常列表；`label`=模型原始类别（英文），`name`=中文名，`targets`=去重后目标数，`count`=检出帧次数，`last_bbox`=[x,y,w,h] 像素 |
| `behavior` | 行为分析汇总；未接入时为 `null`（接入后为对象，不会用 0 冒充） |
| `measurement` | 体长测量汇总；未接入时为 `null`；标定完成前数值均带 `uncalibrated` 标记 |

数据诚实性约定：缺失能力一律 `null`，不用 0 冒充"正常"；`fish_count` 是窗口内可见跟踪目标统计，不代表鱼池存量。

## 5. 视频预览（独立于本报文）

- 地址：`http://<板子IP>:9002/osd.flv`（HTTP-FLV，VLC 或网页 flv.js 播放）
- 画面自带检测框与异常框标注，与文本包互不相干、不要求同步

## 6. 你们需要提供 / 确认的

1. 接收 URL（IP:端口/路径）
2. 是否启用 `X-Device-Token`（启用则发放令牌）
3. 发送模式确认：仅异常才发（默认）还是每窗口都发
4. 对报文字段的增删意见（格式可协商，定稿后板端实现推送）
